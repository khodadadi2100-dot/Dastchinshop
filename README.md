# دستچین V3 — Mobile First + Customer + Admin + Supabase

این نسخه ظاهر V2 را مبنا قرار می‌دهد و لایه واقعی حساب کاربری، آدرس، سفارش و پنل مدیریت را به آن اضافه می‌کند.

## امکانات واقعی
- ثبت‌نام و ورود با Supabase Auth
- پروفایل مشتری
- ذخیره آدرس و مختصات
- سبد خرید و ثبت سفارش واقعی در PostgreSQL
- کم شدن موجودی هنگام ثبت سفارش
- مشاهده سفارش‌های مشتری
- پنل مدیریت دستچین
- مدیریت محصولات، قیمت، موجودی و فعال/غیرفعال
- آپلود تصویر محصول در Supabase Storage
- تغییر وضعیت سفارش
- نمایش مشتری‌ها
- PWA / mobile-first

## راه‌اندازی
1. در Supabase یک پروژه بسازید.
2. SQL داخل `schema.sql` را در SQL Editor اجرا کنید.
3. از Project Settings > API، Project URL و Publishable Key را بردارید.
4. در `supabase-config.js` قرار دهید:
   `window.DASTCHIN_SUPABASE_URL = '...';`
   `window.DASTCHIN_SUPABASE_PUBLISHABLE_KEY = '...';`
5. یک حساب با صفحه اصلی ثبت‌نام کنید.
6. در Supabase SQL Editor برای همان کاربر نقش admin بگذارید:
   `update public.profiles set role='admin' where id='USER_UUID';`
7. کل پوشه را روی هاست استاتیک آپلود کنید؛ `index.html` باید در ریشه باشد.
8. `admin.html` پنل مدیریت است.

## نکته پرداخت
ثبت سفارش در این V3 واقعی است و روش پیش‌فرض «پرداخت هنگام تحویل» است. برای پرداخت آنلاین باید در مرحله بعد درگاه ایرانی موردنظر (مثلاً زرین‌پال/آیدی‌پی و...) و کلیدهای آن اضافه شود؛ کلید محرمانه در مرورگر قرار نمی‌گیرد.

## نکته امنیت
کلید Publishable/anon برای مرورگر است؛ هرگز service_role key را داخل فایل‌های سایت نگذارید. امنیت داده‌ها با RLS و نقش admin کنترل می‌شود.


## وضعیت نسخه متصل
این نسخه به پروژه Dastchin در Supabase متصل شده است. دیتابیس، محصولات اولیه، احراز هویت، آدرس‌ها، سفارش تراکنشی، موجودی و Storage تصاویر محصولات آماده هستند. قیمت‌های فعلی همان مقادیر نمایشی نسخه V3 هستند و موجودی اولیه 100 عدد برای تست است؛ از پنل مدیریت قابل تغییر است.
